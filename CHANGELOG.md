# CHANGELOG

## 0.7.0

Uses the new item API of WTF 1.12 (older system versions keep working without it):

- Item actions group (Inventory): usage roll, +1 / −1 charge, recharge, recharge with a hero die, animate / deanimate (or ask the Referee; deploy / recall rides) and a hallmark's level-up upgrade — the same as the system's right-click menu
- Inventory markers: an hourglass on single-use powers (and albums holding one), a flame on lit items, a star on hallmarks with an upgrade to choose
- Consumables: hovering *Use* lists what it does (the system's own tooltip)

## 0.6.0

Uses the new features of WTF 1.11.0 (older system versions keep working without them):

- Rolls from item features: gear with the *weapon* feature appears in Weapons (damage) and gear with the *album* feature in Power Albums
- Consumables group: *Use* a consumable (the system asks what to restore / apply; targets, else selected tokens, else yourself)
- Light group: light or put out items with the light category or glowing feature; put out a power's light (hidden when the GM turns *Item lights* off)
- Counters group (under Other): the actor's and its items' counters — click +1, right-click −1
- Rest (one week) in the character and NPC *Other* groups
- A run-out item with *Damage when run out* stays active and rolls its damage
- Attack icons use the same colors as the character sheet: each attack takes the color of the ability it is set to roll with
- Existing HUD layouts may need *Reset layout* in the HUD settings to show the new groups
